# roblox-blackhole

Real-time black hole simulation in Roblox using `EditableMesh`.

Simulates an accretion disk with relativistic gravitational lensing, Doppler beaming, gravitational redshift, a photon ring, and lensed background stars computed via numerical null geodesics.

## Usage

Sync into Roblox Studio using [Rojo](https://rojo.space/):

```bash
rojo serve
```

Or build the place file directly:

```bash
rojo build default.project.json -o "BlackHole.rbxl"
```
